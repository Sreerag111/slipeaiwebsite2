# Slipe AI Web Application

Official web application and high-converting landing page for **Slipe AI**, operated by **Pace AI Technologies (OPC) Private Limited**.

---

## 🌟 Key Features

- **Interactive Before/After Split Comparison:** Real-time draggable split slider showcasing authentic vintage photo restoration.
- **Photo Enhancer Suite (10 AI Models):**
  - Clean Up Photos
  - Enhance Photos Quality
  - B&W to Color
  - HDR Clarity
  - Denoise
  - Motion Deblur
  - Creative AI
  - Precision AI
  - Auto Enhance
  - Remove Background
- **Video Remastering Suite:** AI 60fps upscaling, slow-motion interpolation, and precision clarity.
- **Slipe AI Assistant:** Real-time conversational AI for photo restoration advice and creative prompts.
- **Photoroom-Style B&W Paywall:**
  - 2×2 showcase gallery with crisp 2px solid white borders
  - Segmented `[ Lite ]` and `[ Pro ]` switcher
  - Ascending plan cards: Weekly ₹49, Monthly ₹99, Yearly ₹899 (Lite); Monthly ₹599, Yearly ₹1,799 (Pro)
  - Razorpay Web Checkout integration
- **Mobile Integration:** Direct link to Google Play Store download.
- **Corporate Legal Pages:** Privacy Policy and Terms & Conditions.

---

## 🛠 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom Dark Mode Omni-directional Shadows
- **Typography:** Montserrat (Google Fonts)
- **Payments:** Razorpay Web Checkout JS
- **Deployment:** Vercel / Cloudflare Pages / Node.js

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```
